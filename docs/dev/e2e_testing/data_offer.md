# Create Data Offer Page Specifications and User Tests

## Features

### 1. Create an Asset Only
- Allow users to create an asset without additional configurations.
- Ensure compliance with MDS ontology.

### 2. Create an Asset, Policy, and Contract Definition
- Enable users to create an asset along with a policy and contract definition.
- Support the following policy types:
  - **Restricted Policy**: Define new restrictions for asset usage.
  - **Unrestricted Policy**: Always-true policy for unrestricted access.

## User Tests

### 1. Create an Asset Only
- Test asset creation functionality.
- Verify compliance with MDS ontology.
- Ensure the created asset appears in the asset list.

### 2. Create an Asset, Policy, and Contract Definition
- Test creation of an asset with a restricted policy.
- Test creation of an asset with an unrestricted policy.
- Verify that the policy and contract definition are correctly associated with the asset.
- Ensure the created asset, policy, and contract definition appear in their respective lists.
