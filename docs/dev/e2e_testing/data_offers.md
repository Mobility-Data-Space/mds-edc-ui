# Data Offers Page Specifications and User Tests

## Features

### 1. List Data Offers
- Display all data offers available on the connector.
- Include pagination and search functionality for large datasets.

### 2. View Data Offer Details
- Allow users to select a data offer and view detailed information.
- Include metadata such as offer ID, title, description, and associated policies.

### 3. Publish a New Data Offer
- Enable users to publish a new data offer.
- Support publishing with and without manual approval.

## User Tests

### 1. List Data Offers
- Verify that all data offers are displayed correctly.
- Test pagination and search functionality with varying dataset sizes.

### 2. View Data Offer Details
- Test that selecting a data offer displays the correct details.
- Validate the accuracy of metadata fields.

### 3. Publish a New Data Offer
- Test publishing functionality with manual approval enabled.
- Test publishing functionality without manual approval.
- Verify that published data offers appear in the list.
