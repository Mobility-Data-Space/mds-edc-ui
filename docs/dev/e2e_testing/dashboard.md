# Dashboard Page Specifications and User Tests

## Features

### 1. Statistics Display
- Shows the following stats:
  - Consumed Transfer Processes
  - Provided Transfer Processes
  - Number of Data Offers
  - Number of Assets
  - Policies
  - Agreements

### 2. Connector Properties
- Displays the connector properties:
  - Connector ID
  - Endpoint

## User Tests

### 1. Statistics Display
- Verify that all statistics are displayed correctly.
- Test the accuracy of each statistic (e.g., number of transfer processes, data offers, etc.).
- Validate the layout and visibility of the statistics section.

### 2. Connector Properties
- Test that the connector ID and endpoint are displayed correctly.
- Verify the accuracy of the connector properties.
- Ensure the layout and visibility of the connector properties section.
